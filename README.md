# Jayesh Mepani — Developer Portfolio

Live portfolio: https://jayeshmepani.site

This repository contains the source for my personal developer portfolio: a responsive, interactive showcase of systems software, astronomical computation, language tooling, and full-stack applications.

## Featured work

- **Panchang Core & JPL Ephemeris** — Vedic Panchanga calculations backed by a native C ephemeris engine, with PHP, Python, and Dart FFI bindings.
- **CSSForge** — Rust-based semantic CSS refactoring engine and terminal workbench.
- **Lipimala** — Indic transliteration and script-conversion libraries for Dart, JavaScript, Python, and PHP.
- **Hindu Scriptures** — Digital scripture repository and AI Scholar, with a hosted web application and Android WebView companion.
- **Laravel Gemini Translator** — Laravel translation extraction and AI-assisted localization tooling.
- **Poetry Analyzer** — Computational literary and linguistic analysis platform.
- **PostalKit** — Python ctypes binding and runtime loader for libpostal.
- **SQL to Laravel** — Browser-based SQL migration and seeder generator.

The portfolio links to the individual project repositories, where each project's README and documentation are the source of truth for implementation details, supported platforms, versions, and quantitative claims. Metrics shown on the portfolio are summaries and should be kept aligned with those project documents.

## Technology

The portfolio is built with HTML, CSS, and JavaScript, with interactive visual elements and responsive layouts. Refer to the source files and assets in this repository for implementation details.

## Local preview

Clone the repository and serve the project root with any static HTTP server. For example:

```bash
git clone https://github.com/jayeshmepani/Portfolio.git
cd Portfolio
python -m http.server 8000
```

Then open http://127.0.0.1:8000.
